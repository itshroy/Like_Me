# ❤️ React State Practice

A simple React application demonstrating the **useState Hook** through an interactive heart icon.

## Features
- React state management using `useState`
- Interactive heart icon
- Simple and clean UI

## Tech Stack
React.js | JavaScript | CSS | Vite

## Run Locally
```bash
npm install
npm run dev
```
